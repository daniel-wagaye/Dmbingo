Meintenance page
Trigger condition (Client)
 - The client must always subscribe to the current game row via Supabase Realtime.
 - If at any time the client detects:
   - games.phase === 'maintenance'
   then:
    - Immediately stop rendering any game-related UI (picking, started, winner reveal).
    - Redirect or switch view to the Maintenance Page.
    - No further game actions (pick, bingo claim, etc.) are allowed while in this state.
UI (Frontend)
- Fullscreen view with a centered square card.
- Card design:
  - Glassmorphism / frosted-glass effect
  - Soft blur background
  - Rounded corners
  - Subtle shadow
- Content inside the card (center-aligned):
     - Title (bold, prominent):
    - The app is under Maintenance
  - Subtitle (smaller, calm tone):	
    - This will take a couple of minutes.
  - Note text (light emphasis):
    - When finished we will notify the Group
<button type="button" class="maintenance-button"onclick="window.open('https://t.me/DM_Bingo', '_blank')"> DM Bingo Community</button>
    - The button forwards the user to the telegram group.
