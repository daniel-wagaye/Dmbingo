Play button redirects the user to Game pages:
Implement the Play button in the Dashboard component. Use a custom hook useGame() that provides the current game state from a global real‑time subscription (Supabase Realtime). The button must:
- Display a spinner and be disabled while navigation is in progress (prevent double clicks).
  - If currentGame is not yet loaded, the button should be disabled (or show a spinner) and the handler should do nothing.
  - When clicked and not loading, determine the target route based on currentGame.phase:
    - picking → /game_picking
    - started or winner_reveal → /game_started
    - maintenance → /maintenance
    - For any unexpected phase, display a toast message "Game not available" and do not navigate.
Additional requirements:
1. Local navigation‑in‑progress state: Use isNavigating (boolean) to track whether a navigation is ongoing.
2. Temporary unresponsiveness: While isNavigating is true, all other interactive elements (Deposit, Withdraw, Transfer, Support, History, Edit Name, Claim, Language Toggle, Invite) must become unresponsive (no click events) without any visual change.
  - Apply a CSS class (e.g., dashboard-navigating) to the dashboard container.
  - Use CSS pointer-events: none on all children except the Play button’s wrapper.
  - Wrap the Play button in a <div className="play-button-wrapper"> to exclude it from the rule.
3. Safety timeout: Set a timeout (e.g., 300ms) after starting navigation to reset isNavigating to false in case navigation fails or takes too long. Clear the timeout.
4. Cleanup: Use a ref to store the timeout and clear it in a cleanup useEffect.
