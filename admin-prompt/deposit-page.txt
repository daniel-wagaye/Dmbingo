Deposit page (only super admin)
Table columns: deposit_id, telegram_id, first_name, amount, bank, txn_reference, status, created_at, processed_at, actions.
Super Admin can change the deposit status to rejected or approve manually the deposits:
Reject button → modal:
Password input
Reason textarea
Buttons: Close, Reject
On Approve: verify password; if correct → change deposits.status to 'rejected' and log the rejection to admin_actions with reason and admin metadata.
Approve button → modal:
Password input
users telegram_id textarea
Reason textarea
Buttons: Close, Approve
On Approve: verify telegram_id exist in users and verifiy password; if correct → change deposits.status to 'approved', store telegram_id to deposits.telegram_id, credit the user non_withdrawal_wallet by deposits.amount and log the manual approval to admin_actions with reason and admin metadata
