Withdrawals — Pending & Approved

Pending Withdrawals page (For all Admin)
only withdrawals_request.status = 'pending'
Table columns: withdrawal_id, telegram_id, first_name, amount, bank, account_holder, account_num, status, created_at, actions.
Actions: Approve, Decline

Approve modal:
Password input
Admin tx number input (9–21 chars)
Buttons: Close, Approve
On success:
Update withdrawals_request:
status = 'approved'
admin_tx_number = <entered text>
admin_first_name = <admin.first_name>
processed_at = now()
Send Telegram message to user:
"✅ Your withdrawal of {amount} ETB has been successfully credited to your {bank} account."
Log admin_actions.

On success:
Update withdrawals_request:
status = 'declined'
admin_first_name = <admin.first_name>
processed_at = now()
Send Telegram message to user:
"❌ Your request is Canceled due to incorrect information.
Request another withdrawal with correct information"
Log admin_actions.

Decline modal:
Password input
Radio: Incorrect | Bank:
Close / Decline
On Decline:

If Incorrect →
Refund amount to user withdrawal_wallet (credit back)
Update withdrawals_request:
status = 'declined'
declined_reason = incorrect
admin_first_name = <admin.first_name>
processed_at = now()
Send Telegram message to user:
"❌ Your request is Canceled due to incorrect information.
Request another withdrawal with correct information"
Log admin_actions.

If Bank →
Refund Amount to user withdrawal_wallet (credit back) 
Update withdrawals_request:
status = 'declined'
declined_reason = incorrect
admin_first_name = <admin.first_name>
processed_at = now()
Send Telegram message to user:
"🙏 Please choose another bank.
Sorry for the inconvenience!."
Log admin_actions.

Approved Withdrawals page: same page as Pending Withdrawals page but only withdrawals_request.status = 'approved' or 'declined' and read-only (for all admins).
