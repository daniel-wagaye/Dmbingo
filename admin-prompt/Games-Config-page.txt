Games Config page(super admin only)
Controls:
1. Start/Stop toggle
   The toggle reflects game_status.status:
   If game_status.status === 'active'
    → Toggle = ON
    → Label: Game Active
    → Admin can Stop
   If game_status.status === 'stopped'
    → Toggle = OFF
    → Label: Game Stopped
    → Admin can Start
    When toggling Stop → modal asking admin action password.
     - If password valid → set game_status.status = 'stopped' using atomic transaction, 
    When toggling Start → modal asking admin action  password.
     - If password valid → set game_status.status = 'active' using atomic transaction, toast.succses("Game status is changed to ACTIVE.")
      - After succsess
        - POST https://<game-server>/internal/game-control
          Headers:
            Content-Type: application/json
            X-Game-Secret: <SECRET_VALUE>
             Body:
              {"game":"Start"}
          - on success 200 return toast.succses(The game has started successfully)
     - If wrong password → toast.error("password is not correct").
2. Weak Up button:
   under the toggle
   when clicked it posts:
            - POST https://<game-server>/internal/game-control
          Headers:
            Content-Type: application/json
            X-Game-Secret: <SECRET_VALUE>
             Body:
              {"game":"Start"}
          - on success 200 return toast.succses(The game has started successfully)

400 Bad Request:
 - Trigger: Invalid JSON body (not exactly {"game":"Start"}, or extra fields).
 - Response Body: { "error": "INVALID_PAYLOAD" }
401 Unauthorized:
 - Trigger: Missing or invalid X-Game-Secret header.
 - Response Body: Not specified (standard 401 response, possibly empty or with a generic message like "Unauthorized").
409 Conflict:
 - Response Body: { "error": "ALREADY_STARTED", "message": "Game already started or not in maintenance." }
 - Toast: toast.error("Game already started or not in maintenance.")
 - Response Body: { "error": "GAME_STATUS_IS_NOT_ACTIVE", "message": "Game status is not active. can't start game now." }
 - Toast: toast.error("Game status is not active. Can't start game now.")

429 Too Many Requests
 - Response Body: { "error": "RATE_LIMIT_EXCEEDED" }
 - Toast: toast.error("Rate limit exceeded. Please try again later.")

game_config
The game stake amount and picking phase countdown that the super admin can update.
Only one row needed
CREATE TABLE game_config (
    id SMALLINT PRIMARY KEY DEFAULT 1 check(id = 1),  -- Static ID, never changes
    stake_amount NUMERIC(12,2) NOT NULL DEFAULT 10, 
    picking_countdown_end_time INT NOT NULL DEFAULT 30,
    minimum_player SMALLINT NOT NULL DEFAULT 2,
    prize_percent INT DEFAULT 80,
    referral_amount NUMERIC(12,2) NOT NULL DEFAULT 10,
    referral_monthly_limit INT NOT NULL DEFAULT 10,
    registration_bonus NUMERIC(12,2) NOT NULL DEFAULT 10,
    last_updated TIMESTAMPTZ DEFAULT NOW()
);

CREATE TABLE game_status (
    id SMALLINT PRIMARY KEY CHECK (id = 1),
    status TEXT NOT NULL CHECK (status IN ('active', 'stopped')),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT now()
);

admin_actions
To get all audit which admin does what
CREATE TABLE admin_actions (
    action_id BIGSERIAL PRIMARY KEY,
    admin_id BIGINT NOT NULL REFERENCES admins(admin_id) ON DELETE SET NULL,
    action TEXT NOT NULL,   -- e.g., 'credit_user', 'approve_withdrawal', 'decline_withdrawal', 'delete_deposit', 'update_stake', 'login', etc.
    target_id BIGINT,   -- optional: the user_id/withdrawal_id/deposit_id this action relates to
    target_type TEXT,   -- e.g., 'user', 'withdrawal', 'deposit', 'game', 'admin'
    details JSONB DEFAULT '{}'::jsonb -- extra metadata: {"amount":100,"wallet":"withdrawable","tx_number":"ABC123456"}
    ip_address INET,            -- admin’s IP if you want for security/audit
    user_agent TEXT,            -- optional: browser/agent
    created_at TIMESTAMPTZ DEFAULT NOW()
);
