Make the following dashboard cards clickable and reusable:
- Total Players
- Total Played Games
- Total Deposits
- Total Withdraw
- Total Transfer Commission Profit
- Total Profit

Behavior:
1. Each card must become a keyboard-accessible button (tab focusable, activates on Enter and click).
2. Clicking a card opens a shared StatFilterModal. The card passes its statKey (e.g., "deposits", "withdrawals", etc.).
3. The modal displays:
  - Title = card label
  - The unfiltered original value (from dashboard store)
  - Start Date + End Date input (use the existing shared DatePicker)
  - Buttons: Apply, Clear, Close (X)
  - A numeric result area + status text + loading spinner
4. Apply behavior:
  - Validate dates (block if end < start)
  - Show loading state
  - Send request (no page refresh):
GET /admin/stats/{statKey}?startDate=YYYY-MM-DD&endDate=YYYY-MM-DD
axios.withCredentials = true
  - On success:
    - Update the modal result with returned value
    - Show a (Filtered) indicator beside the result
    - If updateCardOnSuccess = true, also update the card’s displayed value
5. Clear behavior:
  - Resets modal value to the original unfiltered value from dashboard store
  - Does not request the server unless a refresh is explicitly needed
6. Error handling:
  - Show error message inside the modal
  - Also show a toast error
  - Provide a Retry button inside modal
7. Accessibility Requirements:
  - Modal uses role="dialog" and traps focus while open
  - Esc closes modal
  - Enter activates Apply when focused
